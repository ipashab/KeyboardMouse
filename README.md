# KeyboardMouse — клавиатурная мышь для macOS

Минималистичное приложение-резидент в строке меню: по глобальному хоткею
включает режим, в котором курсором мыши управляешь с клавиатуры — движение,
клики, перетаскивание, скролл. Все скорости и назначения клавиш настраиваются
в нативном UI. Никаких зависимостей и установщиков, только Swift + macOS API.

## Возможности

- **Режим по требованию** — глобальный хоткей включает/выключает режим
  (по умолчанию `⌥⇧M`, переназначается в настройках). Выход — повтор хоткея
  или `Esc`.
- **Управление курсором** — движение с ускорением при удержании, ускоряющий
  модификатор (по умолчанию `⇧`, множитель настраивается), ограничитель по
  границам экранов (мультимонитор).
- **Клики** — левый, правый, средний, двойной; **перетаскивание** одним
  клавишей (зажал-отпустил логику drag через leftMouseDragged-события).
- **Прокрутка** — вертикальная, с разгоном и переключателем инверсии под
  «естественный» скролл.
- **Прозрачность для остальных клавиш** — незанятые сочетания проходят в
  активное приложение: в режиме можно печатать и пользоваться системами
  шорткатов.
- **UI настроек** — рекордер клавиш (клик по полю → нажал клавишу), ползунки
  базовой/максимальной скорости, времени разгона, скорости скролла, выбор
  ускоряющего модификатора, снятие любого назначения, сброс к дефолтам.
- **Панель-легенда** — всплывает вверху экрана в активном режиме с текущей
  раскладкой; обновляется на лету при смене настроек.
- Настройки сохраняются в UserDefaults (JSON), переживают перезапуски.

## Раскладка по умолчанию

| Действие | Клавиша |
|---|---|
| Включить/выключить режим | `⌥⇧M` |
| Движение | `←` `→` `↑` `↓` |
| Ускорение (удерживать) | `⇧` (×3) |
| Левый клик | `Пробел` |
| Правый клик | `X` |
| Средний клик | `C` |
| Двойной клик | `D` |
| Перетаскивание вкл/выкл | `G` |
| Прокрутка вверх / вниз | `E` / `Q` |
| Выход из режима | `Esc` или хоткей |

Всё, кроме `Esc`, настраивается; любое назначение можно снять.

## Требования

- macOS 14+ (Sonoma и новее)
- Command Line Tools со Swift 5.9+ для сборки из исходников (полный Xcode не нужен)

## Установка из DMG

1. Скачай `KeyboardMouse-1.0.dmg` из [релизов](../../releases).
2. Открой DMG и перетащи `KeyboardMouse.app` в `/Applications`.
3. Первое открытие: приложение ad-hoc подписано (не заверено Apple), поэтому
   Gatekeeper может не пускать двойным кликом. Открой через правый клик →
   «Открыть», либо сними карантин:
   ```bash
   xattr -dr com.apple.quarantine /Applications/KeyboardMouse.app
   ```
4. Выдай разрешение «Управление компьютером» (см. ниже).

## Первый запуск: разрешение Accessibility

Приложение перехватывает клавиши через CGEventTap и эмулирует мышь через
CGEvent — для этого нужно разрешение Универсального доступа:

1. При первом запуске появится запрос — или открой
   **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
2. Включи переключатель напротив **KeyboardMouse**.
3. macOS применяет разрешение к новому процессу: если приложение уже было
   запущено — нажми **«Перезапустить приложение»** (кнопка в окне настроек
   или в меню в строке меню), либо соглашайся на системный диалог
   «Завершить и открыть снова».
4. Готово: `⌥⇧M` включает режим, вверху экрана появляется красная
   панель-подсказка.

> Если пересобираешь приложение сам — ad-hoc подпись меняет CDHash, и
> переключатель в Универсальном доступе нужно включить заново
> (поможет `tccutil reset Accessibility local.pav.keyboardmouse`).

## Сборка из исходников

```bash
git clone https://github.com/ipashab/KeyboardMouse.git
cd KeyboardMouse

swift build          # отладочная сборка
swift test           # юнит-тесты (swift-testing, XCTest не нужен)

./Support/build-app.sh              # соберёт build/KeyboardMouse.app
./Support/build-app.sh release --install   # + установка в /Applications и запуск
./Support/make-dmg.sh               # + соберёт build/KeyboardMouse-<ver>.dmg
```

Иконка приложения генерируется процедурно (`Support/generate-icon.swift`,
CoreGraphics) и вшивается в бандл на этапе сборки — бинарных ассетов в
репозитории нет.

## Архитектура

```
Sources/KeyboardMouse/
├── main.swift              — точка входа (NSApplication, .accessory)
├── AppDelegate.swift       — статус-меню, окно настроек, ожидание TCC, перезапуск
├── ModeController.swift    — event tap, интерпретация клавиш, тиковый таймер 60 Гц
├── MouseActions.swift      — CGEvent: движение, клики, drag, скролл
├── StoredSettings.swift    — модель настроек + классификация клавиш (чистая логика)
├── SettingsStore.swift     — персистентность (UserDefaults + JSON)
├── KeyCodes.swift          — virtual key codes, имена клавиш, лейблы хоткеев
├── SettingsView.swift      — окно настроек (SwiftUI)
├── KeyCaptureButton.swift  — NSView-рекордер клавиш
└── ModeOverlayPanel.swift  — плавающая панель-легенда
Tests/KeyboardMouseTests/   — swift-testing: классификация клавиш, разгон скорости,
                              кодирование настроек, легенда, домены модификаторов
Support/                    — Info.plist, скрипты сборки иконок/бандла/DMG
```

Ключевые решения:

- **CGEventTap** (annotated session tap) вместо Carbon-хоткеев: единый
  перехватчик и для глобального хоткея, и для клавиш режима; умеет поглощать
  события (auto-repeat, лишние keyUp) — требует то же разрешение
  Accessibility, что и эмуляция мыши.
- **Движение — таймером 60 Гц**, а не по key-repeat: плавность не зависит от
  системных настроек автоповтора; скорость — функция времени удержания
  (базовая → максимум за время разгона).
- **Классификация клавиш вынесена в чистые функции** `StoredSettings` —
  покрыта юнит-тестами без CGEvent/мониторов.
- **Модификаторы нормализуются** до 4 device-independent битов — мусорные
  device-dependent биты и Caps Lock не ломают сопоставление хоткеев
  (проверено тестом на совпадение доменов NSEvent/CGEventFlags).

## Ограничения

- Скролл вертикальный.
- Разрешение TCC привязано к подписи: после пересборки с новой ad-hoc
  подписью включать заново. Для «установил и забыл» — собирай и не
  пересобирай.
- Не подписан Developer ID: скачанный DMG требует ручного «Открыть» или
  снятия карантина (см. Установка).
